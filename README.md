# The Painfully Honest Out-of-Office

An out-of-office auto-reply that tells the private truth — the inbox holds 4,318 unread messages and replies will come in order of panic, not arrival — wrapped in a warm thank-you and a clear return date, so a manager could let it stand. One sentence, 145 characters.

> Thank you for your email, I am away until Monday, and honestly your message joins 4,318 unread ones I will answer in order of panic, not arrival.

`main.py` writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
